# Глоссарий

Термины проекта в единой трактовке. Все документы используют эти определения.

| Термин | Определение |
|---|---|
| **Ротация** | Механизм повторения слова до его заучивания. Слово «попадает в ротацию» после ответа «Я не знал» на новой карточке или из ручного повторения (не в MVP). |
| **Этап (stage)** | Номер повторения в ротации: 1–8. Каждому этапу соответствует интервал до следующего показа. |
| **Интервал** | Время от подтверждения до следующего показа: 5 мин → 1 ч → 1 день → 1 нед → 1 мес → 3 мес → 6 мес → 12 мес |
| **Лестница повторений** | Таблица «этап → интервал». Идём по ней вверх при каждом «Я запомнил». |
| **Due-карточка** | Карточка этапа ротации, чей `next_review_at <= now` — время показа наступило. |
| **Очередь** | Не физическая структура, а выборка: due-карточки по `ORDER BY next_review_at ASC`, затем новые слова, затем empty state. |
| **Новое слово** | Слово словаря, по которому у пользователя нет записи progress. Всегда карточка EN → RU, перевод скрыт. |
| **«Я уже знаю»** | Ответ на новое слово: статус `already_known`, слово исключается из очереди навсегда (не повторяется). Попадает в статистику. |
| **Memorized (выучено)** | Статус после 8-го успешного подтверждения этапа. `next_review_at = NULL`, исчезает из очереди. |
| **idempotency_key** | Строка-ключ от клиента (генерируется при показе карточки), защищает от двойной отправки ответа: повторный `POST /reviews` с тем же ключом возвращает сохранённый результат, ничего не меняя. |
| **Stale card (409)** | Клиент прислал ответ по карточке, чей этап уже устарел на сервере (например, ответ по оффлайн-дубликату). Сервер возвращает 409 с актуальной карточкой. |
| **Быстрые повторы (quick_repeat_step)** | Цикл восстановления после «не запомнил»: два повтора через 5 мин и через 1 ч (`quick_repeat_step` 1 → 2), затем выход на следующий этап N+1 (D-02, WS-3). |
| **Ориентация карточки** | EN → RU (переводим с англ.) или RU → EN (с русского). Новое слово — всегда EN → RU; в ротации — случайно при каждом показе. |
| **Синк прогресса** | Выгрузка локального прогресса с девайса на бэк + скачивание обновлений словаря (§2.1.4, WS-2). |
| **RBAC** | Доступ по ролям: user / moderator / admin. Проверяется на каждом запросе админки (sq-4). |
| **Optimistic locking** | Контроль параллельного редактирования по `version` (If-Match). Конфликт → 409 + актуальные данные (sq-4). |
