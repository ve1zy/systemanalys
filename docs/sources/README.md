# Исходные файлы (source of truth)

Оригинальные наработки проекта, из которых сгенерировано содержимое `docs/`.
При расхождении текста в `docs/` с этими файлами **верны оригиналы** — обновите зеркало.

| Файл | Что содержит | Версия / дата |
|---|---|---|
| `Проект_приложение_по_обучению_английскому_языку.docx` | Техническое задание: описание проблемы, концепт (web-приложение, бэкенд, админка), модули, флоу авторизации, ротация, таблицы БД | — |
| `tbank-english-learning-uml.drawio` | UML-модель MVP из 6 диаграмм (страницы в файле): `uc-context` (UC-1), `uc-learning` (UC-2), `sq-auth` (SQ-1), `sq-next-card` (SQ-2), `sq-review` (SQ-3), `sq-admin` (SQ-4) | v1.0 · 25.10.2026 |

### Как перегенерировать зеркала

1. `docs/requirements/01-tz.md` — из содержимого docx (разделы 1–2.3).
2. `docs/diagrams/*.md` — из соответствующих страниц drawio (id страницы указан в шапке каждого файла). Mermaid не является полной заменой drawio: структурные элементы (рамки, легенда, примечания) передаются в виде Markdown, сообщения последовательностей — как `sequenceDiagram`.

Файлы docx/drawio открываются в Word и app.diagrams.net соответственно.
